Architecture & Compliance

About MailShield AI

Engineering standards, mathematical foundation, and privacy architecture.

📐 Mathematical Foundation

The backend implements a pure Java Multinomial Naive Bayes classifier. Under the naive assumption that token occurrences are conditionally independent given the class:

log P(c|D) = log P(c) + Σ count(w, D) · log P(w|c)

Laplace smoothing (α = 1.0) guarantees that zero probabilities never occur for words unseen in a particular class. Logarithmic probabilities prevent floating-point underflow, and the Log-Sum-Exp algorithm guarantees exact posterior normalization.

🔒 Security & Privacy Notice

MailShield AI was architected from the ground up to respect enterprise confidentiality:

  • No External API Calls: All NLP parsing and machine learning inference occurs locally inside your JVM.
  • Zero Raw-Body Persistence: Full message bodies are discarded immediately after in-memory scoring.
  • Attachment Isolation: Attachments inside .eml files are never saved to disk, opened, or executed.
  • XSS Defensive Filtering: All email HTML is stripped using JSoup and escaped before presentation.
